## 实现约束

- 源码仅 `C:/Users/jch/heimaoai/project`。
- 公共目录放在 `filesDir/workspaces` 外部，防止目录集合校验和删除相互影响。
- 不增加 Room schema 版本；工作区使用独立的环境选择标识。
- 无标识视为原私有环境；旧 Linux 不自动合并、迁移或清除。
- AI 与终端共用有效 Linux 路径，但保持现有不同挂载范围。
- 公共维护需要独占；运行中的任务或终端应返回占用提示，不能被静默杀掉。
- 归档按工作区完整携带有效 Linux 与该项目 HOME；恢复不激活公共环境引用。
- 不覆盖正式 App 的用户数据来做测试，设备验证采用隔离测试包。

## 备份调查事实

开始任务时的 HEAD 为 `00e93911`，已经有两项旧故障相关修复：

1. `WorkspaceRuntime.repairProotRootfsPlaceholders` 修复 PRoot 留下的 rootfs 根级零权限挂载占位目录；否则 `Files.list` 可能拒绝访问。这能解释为什么没有工作区时不触发错误。
2. `RoomSchema30` 将显式 `DEFAULT NULL` 和无默认值做等效比较；已有 `RoomSchema30Test` 覆盖历史迁移生成的 `source_paths DEFAULT NULL`。

这两项不是本任务新实现。没有用户原始报错与对应旧 APK，不能据此认定唯一根因；本任务补共享归档及含工作区数据的回归验证。
